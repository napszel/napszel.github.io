Climbing Routes (2018, HTML, Javascript, CSS)

A web application that displays up to date information of the currently available boulder and sport routes at Gaswerk and Milandia climbing gyms of Zürich, Switzerland. You can read about each existing and planned features in the project's PDF documentation or checkout the source code on GitHub.

Clean Energy Mapping (2017, HTML, CSS)

My team's project on the 2017 Climathon Zürich. Climathon is a 24 hour hackathon event where participants are encouraged to work on climate related challenges for a greener future. This webpage was written in 24 hours from scratch, including coming up with the project concept.

The main component of the page is mapping the clean energy sources of Switzerland (wind, solar, hydro and nuclear) and educating users of their differences and energy effectiveness. Three of us worked on it, 2 developers, 1 content contributor.

Patterns (2004, Pascal)

This is not really a game, rather something interesting. This is an implementation of the classical 8 queens on a chessboard problem (putting 8 queens on a chessboard so that they don't hit each other) which has many solutions but that is not the point. The point is in the patterns that forms when you put the chessboards next to each other.

Buttons to use:
up and down arrows to zoom in and out
r key draws the outline of the boards
t key removes the outline
Return key shows you the next solution of the problem
Backspace shows the previous solution




Bunny (2003, Pascal)

My first graphical game. The aim is to get from the bottom left corner to the top right corner with the bunny. It can push around boxes and collect-reuse carrots to make itself a path.

There are many levels made for it but you can also write your on levels in a simple text file which the program can read in. These features and help are available from the main menu.


Digging (2003, Pascal)

The game is set under ground and played by 2 players. You both control a happy face character and you have to dig your way around the field (exploding the ground around you) and collect dollars. You can also shoot at each other. You win the game by either collecting all the dollars or by killing your opponent.

There is one default level to this game, but you can write your on levels in a simple text file which the program can read in. These features and help are available from the main menu.


Cheesy Labyrinth (2003, Pascal)

My first game using only character graphics.

The goal is to collect little pieces of cheese in a labyrinth. For help, there are some bombs on the way which you can collect and then later use (with Space button) to explode the walls around you.

There is one default level to this game, but you can write your on levels in a simple text file which the program can read in. These features and help are available from the main menu.
