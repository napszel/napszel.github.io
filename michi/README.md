# Michael Konitzer — Professional Website

A responsive, bilingual (German/English) static portfolio website.

## Preview locally
Open `index.html` in a modern browser. No build step is required.

## Publish later
Upload these files to a GitHub repository and enable GitHub Pages. Before public launch:
- Confirm all wording and career dates.
- Add a portrait if Michi wants one.
- Add his preferred professional contact details / LinkedIn URL.
- Review whether he wants the current employer and industry details displayed publicly.

The colour system uses deep navy, slate blue, cyan and high-contrast neutrals; important meaning is not conveyed by colour alone.
